# Contributing

Use Node20.19+ and npm ci. Run npm run build, npm test, and npm pack --dry-run before submitting. For capture/render changes also run npm run demo with an installed Chrome/Chromium and FFmpeg. Describe checks actually performed and attach nonprivate evidence.

Separate protocol handling from services; add validated schemas and structured errors to tools. Never add arbitrary shell execution, implicit remote uploads, unaudited project script execution, secret-bearing fixtures, or generic advice pretending to be measured analysis. Creative judgment belongs to the AI client; objective claims need evidence. Add regression tests for authorization, invalid inputs and meaningful changed behavior. Cross-platform contributions are welcome: macOS is the currently demonstrated environment. Do not claim Windows/Linux validation without running it.
